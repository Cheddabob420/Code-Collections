# QuickJot

QuickJot is an note taking application to quickly take input and write it to a daily log file to keep track of tasks done
during the shift to put them into the EOS email.

CLI:
    just a text version with only one note and one menu

Ncurses:
    ncurses version that makes a notes folder in you home dir, it can make, wiew, delete, and append to multiple notes with interactive menus
